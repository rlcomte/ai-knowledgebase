<Definition term={"Prompt Engineering"}>
Prompt engineering is the design of instructions, examples, constraints, schemas and interaction patterns that steer a model toward useful, testable behaviour for a specific task. In production it is not just wording: it includes prompt versioning, input validation, structured outputs, retrieval context, refusal boundaries, regression tests and measurement of failure cases.
</Definition>

## Why It Matters

Prompt engineering designs instructions and examples that elicit useful model behaviour. It includes task definition, constraints, output schemas, examples and explicit uncertainty handling.

A prompt is only one part of the context. Treat it as an interface contract for a model call, then verify the resulting behaviour with representative examples rather than relying on phrasing alone.
