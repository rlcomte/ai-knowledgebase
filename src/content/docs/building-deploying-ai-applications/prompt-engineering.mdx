## Why It Matters

Prompt engineering designs instructions and examples that elicit useful model behaviour. It includes task definition, constraints, output schemas, examples and explicit uncertainty handling.

A prompt is only one part of the context. Treat it as an interface contract for a model call, then verify the resulting behaviour with representative examples rather than relying on phrasing alone.
