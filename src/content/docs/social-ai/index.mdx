## Conceptual Story

Social AI studies agents whose behavior is organized around ongoing interaction with people. The important unit is not a single prompt or model completion, but a persistent system that maintains state, memory, goals, skills, identity, relationship models, policies and evaluation over time.

A long-lived adaptive social AI agent is a model-independent agentic system. The foundation model supplies reasoning and generation, but continuity lives in the harness: the governed architecture that decides what is remembered, what is forgotten, which skills are available, which actions require approval, and how adaptation is validated.

This section extends the agent concepts already used elsewhere in the knowledge base into social settings: personalization is not enough; the agent must represent the user, itself, the relationship and the social context without collapsing observation, inference and commitment into one hidden profile.
