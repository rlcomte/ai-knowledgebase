<Definition term={"Co-adaptation and Trust"}>
Co-adaptation means the agent learns with the user, not merely about the user. Trust is calibrated confidence that the agent is competent, honest, boundary-respecting, corrigible and governable.
</Definition>

## Why It Matters

Ordinary personalization is often unilateral: the system observes, profiles and modifies outputs. Co-adaptation is negotiated. The agent observes a pattern, forms a tentative hypothesis, tests it through behavior or dialogue, invites correction, and only then updates memory, policy or skill at the right level.

This matters because social agents shape users as well as adapt to them. An agent that always anticipates preferences may reduce reflection. An agent that always agrees may reinforce errors. An agent optimized for engagement may cultivate dependence. Making adaptation discussable helps preserve user agency.

Trust is broader than answer accuracy. It includes memory correctness, privacy, refusal, restraint, role integrity, uncertainty calibration and repair. A trustworthy agent distinguishes "you told me," "I inferred," "I might be wrong" and "this is a hypothesis worth checking."

<EngineeringMode>
Build correction and repair into the core workflow. Users should be able to inspect consequential memories, correct relationship interpretations, revoke autonomy and see the correction affect future behavior. Hidden personalization is especially risky when it uses relational knowledge.
</EngineeringMode>

<EvaluationCheck>
Test whether the agent accepts correction, revises memory, reduces confidence appropriately and avoids using personal memory to pressure the user.
</EvaluationCheck>

<RealExample>
If an agent infers that a user wants more challenge, it should test that as a tentative interaction style rather than silently becoming more confrontational across all contexts.
</RealExample>
