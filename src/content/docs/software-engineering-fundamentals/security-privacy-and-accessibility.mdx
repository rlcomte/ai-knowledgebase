<Definition term={"Security, Privacy and Accessibility"}>
Security protects systems, data and users from unauthorised access or misuse. Privacy governs how personal or sensitive data is collected, processed, retained and exposed. Accessibility ensures people with different abilities can use the system effectively. AI applications add specific concerns such as prompt injection, tool abuse, data leakage, unsafe outputs, consent, trace retention and accessible review of generated content.
</Definition>

## Why It Matters

Security engineering includes threat modelling, least privilege, secure defaults, secrets management, dependency control, input validation and incident response. AI-specific threats include prompt injection, data exfiltration and unsafe tool use.

Privacy engineering covers data minimisation, purpose limitation, consent or lawful basis, retention, access control and privacy-preserving logs. Context and traces can contain more sensitive information than developers expect.

Accessibility and inclusive design ensure applications work for people with diverse abilities, languages, devices and contexts. AI output must not undermine otherwise accessible interaction.

<EngineeringMode>
Security, privacy and accessibility constrain every AI design choice. Architecture must protect prompts, retrieved context, tools, logs and generated outputs. Design must work for keyboard users, screen readers and people who need clear consent or correction paths. Build work includes threat modeling and privacy tests. Operations monitor abuse, leakage and exclusion. The risk is treating AI features as exempt from normal software duties.
</EngineeringMode>

<RealExample>
A ChatGPT Enterprise rollout shows ordinary engineering concerns around AI. Administrators must configure identity access, connector permissions, retention policy and sensitive-data controls, while designers check accessibility for generated summaries, keyboard flows and screen-reader output. AI features inherit the same security and inclusion obligations as other software.
</RealExample>
