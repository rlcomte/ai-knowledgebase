<Definition term={"Testing and Testability"}>
Testing checks whether software behaves as intended under known conditions, while testability is the degree to which a system can be controlled, observed and isolated during those checks. AI systems need conventional unit, integration and end-to-end tests for deterministic code, plus evals and error analysis for probabilistic model behaviour, retrieval quality and tool-use workflows.
</Definition>

## Why It Matters

The testing pyramid combines unit, integration, contract, system and acceptance tests. Traditional tests verify deterministic behaviour; evals verify probabilistic behaviour. Both are needed in AI applications.

Testability means designing components so dependencies, data and model calls can be controlled or substituted. It makes failures reproducible and lowers evaluation cost.
