<Definition term={"Coding-assistants versus coding-agents"}>
Een coding-assistant reageert vooral op lokale prompts van de ontwikkelaar, zoals het uitleggen van een bestand, code aanvullen of een refactor voorstellen. Een coding-agent is een doelgericht systeem dat een repository kan inspecteren, tools kan kiezen, bestanden kan bewerken, commando’s kan uitvoeren, resultaten kan observeren en kan itereren totdat een stopconditie is bereikt. Dit onderscheid is belangrijk omdat agents sterkere taakafbakening, permissies, bewijs en review nodig hebben dan conversatiegerichte assistentie.
</Definition>

## Waarom dit ertoe doet

Een coding-assistant wordt vooral gebruikt om toe te lichten, autocompletion te bieden of een lokaal fragment te genereren. De gebruiker beheert doorgaans de omliggende workflow.

Een coding-agent is een doelgericht systeem dat code kan inspecteren, tools kan gebruiken, bestanden kan wijzigen, verificatie kan uitvoeren en met enige autonomie over meerdere stappen kan itereren. Dit onderscheid is belangrijk omdat het gebruik van agents het engineeringwerk verschuift naar taakafbakening, contextontwerp, verificatie en review.

<EngineeringMode>
Het onderscheid raakt permissies, workflow en review. Assistants houden de mens doorgaans in de bewerkingslus; agents kunnen een hele repository inspecteren, wijzigen en commando’s uitvoeren. De architectuur moet dat machtsverschil weerspiegelen. Het ontwerp moet zichtbaar maken wanneer de tool suggereert versus daadwerkelijk handelt. Build-werk voegt tests en audittrails toe. Het risico is permissies op agentniveau geven aan een tool die sociaal wordt behandeld als autocomplete.
</EngineeringMode>

<RealExample>
GitHub Copilot-autocomplete is een coding-assistantpatroon: het suggereert code terwijl de ontwikkelaar stuurt. Een repository-bewuste agent gedraagt zich anders wanneer die een wijziging plant, meerdere bestanden bewerkt, tests draait en op falen reageert. Beide zijn nuttig, maar ze vragen om andere review- en permissiepraktijken.
</RealExample>
