## Conceptueel verhaal

Een coding assistant stelt code voor naar aanleiding van een lokaal verzoek. Een coding agent kan een doel nastreven via meerdere stappen: een repository inspecteren, bestanden doorzoeken, een plan vormen, code bewerken, commando’s uitvoeren, testresultaten observeren en zijn werk herzien. De praktische competentie komt voort uit de combinatie van model, harness, tools, context, machtigingen en feedback.

De menselijke rol verschuift van elke regel schrijven naar het vormgeven van de werkomgeving van de agent en het beheersen van de engineering-loop. Hoogwaardig agentwerk begint met een begrensde taak, relevante context, duidelijke randvoorwaarden en verifieerbare afrondingscriteria. De engineer beoordeelt vervolgens bewijs, niet slechts vloeiende verklaringen of een grote diff.

Meerdere agents voegen nog een laag toe. Onafhankelijke taken kunnen parallel worden gedelegeerd, of gespecialiseerde rollen kunnen in een workflow worden gecoördineerd. Dit kan contextvervuiling en doorlooptijd verminderen, maar het voegt tokenkosten, communicatieverlies, bewerkingsconflicten en orkestratie-overhead toe. Multi-agent-ontwerp is daarom een engineeringkeuze, geen volwassenheidsbadge.
