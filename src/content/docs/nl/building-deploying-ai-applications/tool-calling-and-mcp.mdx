<Definition term={"Tool calling en MCP"}>
Tool calling stelt een model in staat een gestructureerde bewerking aan te vragen, zoals een opzoekactie in een database, een berekening, een bestandshandeling of een API-aanroep, terwijl de omringende applicatie de argumenten valideert, de bewerking uitvoert en resultaten teruggeeft. MCP, het Model Context Protocol, standaardiseert hoe hostapplicaties modellen verbinden met externe tools en databronnen, zodat integraties begrepen kunnen worden als expliciete capaciteitsgrenzen.
</Definition>

## Waarom dit ertoe doet

Tool calling stelt een model in staat een gedefinieerde bewerking aan te vragen, zoals het bevragen van een database, code uitvoeren of een API aanroepen. De applicatie, niet het model, moet argumenten, machtigingen, resultaten en neveneffecten valideren.

Model Context Protocol is een open protocol voor het verbinden van AI-applicaties met tools, databronnen en herbruikbare capaciteiten via standaardinterfaces. MCP verbetert de interoperabiliteit; het neemt niet de noodzaak weg van authenticatie, autorisatie, validatie en vertrouwensgrenzen.

<EngineeringMode>
Tool calling verandert architectuur van tekstgeneratie naar gecontroleerde actie. Interfaces hebben getypeerde invoer, machtigingen, time-outs, retries en auditlogs nodig. Productontwerp moet de bevoegdheid van tools zichtbaar maken wanneer acties gebruikers of data raken. Bouwwerk omvat validatie, idempotentie en foutafhandeling. Operations houdt mislukte oproepen en neveneffecten bij. Het risico is een welsprekend model krachtige tools laten triggeren zonder contracten op engineeringniveau.
</EngineeringMode>

<RealExample>
Een coding agent die een bug repareert, zou niet alleen een patch moeten beschrijven. Een tool-aware harness kan het de repository laten doorzoeken, de falende test lezen, het bestand bewerken en het commando opnieuw uitvoeren. MCP generaliseert dit patroon door agents gestructureerde, geautoriseerde toegang te geven tot externe systemen via expliciete toolcontracten.
</RealExample>
