## Conceptueel verhaal

Een AI‑applicatie is niet simpelweg een gewone applicatie met een model eraan gekoppeld. Een deel van het gedrag is probabilistisch: hetzelfde type input kan verschillende outputs opleveren, en een plausibele output kan toch onjuist zijn. De AI‑engineer bouwt daarom betrouwbaarheid rondom een van nature onvolmaakt component.

Het verhaal begint bij het begrijpen van de modelfamilie. Klassieke machine learning leert koppelingen uit data; deep learning leert representaties met neurale netwerken; LLM's genereren taal en andere modaliteiten token voor token. Een bruikbare applicatie voorziet het model vervolgens van de juiste context, verankert het in betrouwbare data, geeft waar nodig tools en organiseert modelaanroepen in een workflow. Evals sturen elke iteratie. Productie-engineering voegt beveiliging, observability, kostenbeheersing, latentiebeheer en feedbackloops toe.
