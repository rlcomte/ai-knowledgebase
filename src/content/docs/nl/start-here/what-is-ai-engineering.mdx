AI Engineering combines AI knowledge, software engineering, effective use of coding agents and the judgement required to decide what should be built.

The field is not only model prompting. It includes shaping the user problem, building model-backed application behaviour, engineering reliable software around probabilistic components, and using coding agents without giving up human responsibility for quality and risk.

The organising frame for this knowledge base is Andrew Ng's <a href="https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map/">AI Engineering Skills Map</a>, published in DeepLearning.AI's <em>The Batch</em>. This site builds from Ng's four-area framing while making explicit where the curriculum extends the source material.

Another useful lens is the distinction between [Software Engineering for AI and AI for Software Engineering](/nl/start-here/ai-engineering-two-directions/). One direction asks how to engineer systems that contain AI. The other asks how to use AI to perform software engineering. Modern AI engineering increasingly combines both.
