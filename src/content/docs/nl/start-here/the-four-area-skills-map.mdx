De vier gebieden zijn:

1. AI-applicaties bouwen en uitrollen
2. Basisprincipes van software engineering
3. Coding agents gebruiken
4. De bouwopgave vormgeven

Ng presenteert deze gebieden als elkaar versterkend. AI-applicaties bevatten probabilistische componenten, dus betrouwbare engineering vraagt om sterke fundamenten in software engineering, gedisciplineerde evaluatie en iteratieve verbetering. Coding agents versnellen de implementatie, maar maken specificatie, architectuur, verificatie en menselijk oordeel juist belangrijker. Het vormgeven van de bouwopgave verbindt engineering-activiteiten met echte gebruikers- en organisatiewaarde.

De gedetailleerde structuren voor Gebieden 2-4 op deze site vormen een praktisch curriculum en een kennisarchitectuur; het is geen bewering dat Ng elk concept heeft gespecificeerd.
