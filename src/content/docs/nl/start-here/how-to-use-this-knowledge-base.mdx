Lees eerst een gebiedsoverzicht wanneer je een onderwerp vanaf nul leert. Gebruik conceptpagina’s als snelle naslag. Volg links naar gerelateerde concepten wanneer een beslissing grenzen overschrijdt tussen productvormgeving, AI‑gedrag, softwarekwaliteit en agent-ondersteunde implementatie.

Elke conceptpagina volgt een compact sjabloon: definitie, waarom het belangrijk is, engineering‑modus, evaluatiecheck, praktijkvoorbeeld, gerelateerde concepten en bronnoot. Korte concepten blijven beknopt in plaats van te worden opgevuld met generieke tekst.



<SourceNote>
De opzet van de site volgt Andrew Ng’s <a href="https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map/">AI Engineering Skills Map</a>, gepubliceerd door DeepLearning.AI in <em>The Batch</em>. Ng’s kaart is de primaire bron voor de vier gebieden. Gebied 1 volgt Ng’s meer gedetailleerde uitwerking; gebieden 2‑4 zijn de beredeneerde uitbreiding op deze site.
</SourceNote>
