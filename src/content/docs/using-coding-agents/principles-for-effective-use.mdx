<Definition term={"Principles for Effective Use"}>
Principles for effective coding-agent use are operating rules that make agent work bounded, reviewable and reversible. They include writing precise task briefs, loading project instructions, limiting permissions, requiring tests or evals, keeping diffs small, asking for evidence, separating exploration from edits and preserving human ownership of consequential decisions.
</Definition>

## Why It Matters

Effective coding-agent use starts by bounding the task, supplying intent, defining done and making context discoverable.

Prefer small diffs, use progressive autonomy, keep humans at decision boundaries, trust verification rather than fluency, turn corrections into infrastructure and preserve reversibility. These principles make agent work reviewable and reduce the chance that speed hides weak engineering.
