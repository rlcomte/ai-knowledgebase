Real world examples connect the knowledge base concepts to concrete systems, constraints and delivery decisions.

Each example should show how the four areas reinforce each other:

- Shaping the build defines the user, workflow, value, risks and human decision boundaries.
- Building and deploying AI applications designs the model workflow, grounding, tools, evals and runtime behaviour.
- Software engineering fundamentals make the system reliable, secure, observable and maintainable.
- Using coding agents can accelerate implementation, testing, documentation and migration work when the task is well-scoped.
